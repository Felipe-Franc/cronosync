MVP de plataforma SaaS para profissionais autônomos, clínicas e pequenas operações comerciais organizarem agenda, leads, atendimentos e faturamento em um único painel.

Projeto construído em **PHP puro com arquitetura MVC própria**, sem frameworks — para demonstrar domínio das fundações da web.

## 🛠️ Stack

- PHP 8.3 com MVC manual
- MySQL/MariaDB + PDO com prepared statements
- HTML5, CSS3 e JavaScript ES6+
- Autenticação com bcrypt e sessões PHP
- Apache via Laragon
